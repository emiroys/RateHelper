# RateHelper v5.0.3

- **Overlay pill:** Language, trip goal, or auto-complete changes apply right away on an open pill — completed-trip count stays correct.
- **Vibration:** Accept and reject feel different (steering wheel too) — you know which counter moved without looking.
- **Startup:** Counters no longer flash as if your week was wiped — you wait until data is loaded.
- **Cancellations:** No more false “no cancellations left” warning at the start of a new week with zero trips.
- **Earnings:** Hourly rate and net profit stand out more; fuel amounts paste correctly; screen stays on on earnings and radar.
- **Faster:** App opens a bit quicker.
