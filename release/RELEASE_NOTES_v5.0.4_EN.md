# RateHelper v5.0.4

*(15 October 2026)*

- **Dedicated Settings screen:** The long inline settings block and **⋮** menu are gone. Tap the **gear** for driving mode, pill orientation, language, auto-update, steering-wheel keys, and more. Week reset, plate badge, and version stay on home.
- **Weekly archive cards:** The **Logs** tab lists reset weeks as expandable cards with **Goal met** / **Goal missed** for that week’s acceptance and cancel thresholds. A second reset in the same week merges into one row.
- **Collapsible overlay:** Tap the pill’s **acceptance %** to shrink to a circular **R** bubble (~48 dp) so more of the map stays tappable; tap **R** to expand again.
- **Live home counters:** Pill +/− updates the home screen immediately without leaving the app.
- **GitHub opt-in (once):** First launch asks about automatic updates and Kraków events. Both off = no network on startup unless you enable them in **Settings**. Trip and earnings data stay on device.
- **Update check:** **Check for updates** lives in **Settings** (last check time and installed version). APK downloads only after you tap update in the dialog.
- **Safer installs:** Downloaded updates must pass signature and version checks before the Android installer opens.
- **Plate badge:** Home footer signature reads **KK383CT**.
